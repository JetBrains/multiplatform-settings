To build the project configure:

```properties
kotlin_repo_url=https://maven.pkg.jetbrains.space/kotlin/p/kotlin/dev
kotlin_version=2.1.0-dev-8803
kotlin_language_version=2.0
kotlin_api_version=2.0
```

in gradle.properties on the root level and inside `convention-plugins`
The just run `./gradlew build` in root project
